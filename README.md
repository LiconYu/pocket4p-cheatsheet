## 参数逻辑

### 核心原则

```
M手动模式下，快门 = 曝光补偿
想暗 → 加快门（1/60 → 1/120 → 1/250）
想亮 → 减慢门 或 加ISO
白平衡控冷暖，胶片影调控色彩
```

### 两个预设

| 预设 | 名称 | 适用场景 | 胶片影调 |
|------|------|----------|----------|
| C1 | 白天通用 | 山景/街景/水景/蓝天 | NC 负片 70% |
| C2 | 日落暖色 | 日落/黄昏 | 暖调 70% |
| 默认 | Auto + 低光 | 夜景 | NC 负片 50% |

### 六场景快速对照

| 场景 | 用哪个 | 要改什么 |
|------|--------|----------|
| 山景 | C1 | 不用改 |
| 水景清澈 | C1 | 快门→1/250，WB→4800K |
| 水景丝滑 | C1 | 快门→1/30，ND→32，WB→4800K |
| 蓝天 | C1 | 快门→1/120，WB→4800K |
| 街景 | C1 | 暗处ISO→200-400 |
| 日落 | C2 | 快门→1/120，长按锁曝光 |
| 夜景 | 默认模式 | 开低光模式，不装ND |

### 雨景四拍（桂林雨天专属）

| 场景 | 模式 | 要改什么 |
|------|------|----------|
| 烟云山水 | C1 | ISO→200-400，不装/ND8，WB→5000K |
| 清水(雨后) | C1 | 快门→1/250，WB→4800K |
| 水流拉丝 | 慢动作120fps | 快门→1/240，ND32，WB→4800K |
| 落雨定格 | 慢动作240fps | 快门→1/480+，不装ND，ISO→400-800 |

### 多云天参数（桂林常见天气）

| 场景 | 普通10bit 直出 | D-Log 2（后期） |
|------|---------------|-----------------|
| 多云山景 | WB 5500K, NC 70%, ISO 100-400 | ISO 200, 向右曝光 |
| 想拍蓝天 | WB 4800K, 快门 1/120, CC冷白 70% | WB 5200K, 后期拉蓝 |
| 云雾山水 | WB 5000K, NC 70%, 快门 1/60 | ISO 200, 向右曝光保云 |
| 水景 | WB 4800K, 快门 1/250, ISO 100-200 | ISO 200, 向右曝光 |
| 日落(多云) | C2 暖调 70%, 快门 1/120 | ISO 200, 向右曝光 |

**D-Log 2 后期流程**（手机剪映即可）：套官方 LUT → 压高光提暗部 → 饱和度+10~20 → 导出 4K H.265

**存储空间**（103G卡）：普通直出 ~137分钟 / D-Log 2 ~73分钟 / 慢动作120fps ~68分钟。建议每晚导出素材。

## 完整参数

### C1 白天通用预设

```
模式：视频 4K 30fps
曝光：M 手动
快门：1/60
ISO：100
白平衡：手动 5200K，色调 0
胶片影调：NC 负片 70%
纹理：-1
去噪：0
ND：晴天 ND16 / 阴天 ND8
```

### C2 日落暖色预设

```
模式：视频 4K 30fps
曝光：M 手动
快门：1/60
ISO：100
白平衡：手动 5200K，色调 0
胶片影调：暖调 70%
纹理：-1
去噪：0
ND：ND4
```

### 夜景（默认模式）

```
模式：低光视频（4K 30fps）
曝光：Auto
ISO：100-1600
ND：不装
白平衡：手动 4800K
胶片影调：NC 负片 50%
```

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| ISO 调不到 100 | 开了 D-Log | 关 D-Log，用普通色彩模式 |
| EV 曝光补偿调不了 | M 模式下 EV 不可调 | 用快门代替（加快门=变暗） |
| 图像调节只有纹理和去噪 | 开了胶片影调 | 正常现象，纹理-1，去噪0 |
| 找不到自定义模式 C1/C2 | 没开 PRO 或没切 M 模式 | 先开 PRO→切 M→底部上滑找 C1/C2 |

## 技术备注

- Pocket 4P 广角 ISO 范围：100-25600
- 中焦 ISO 范围：50-25600
- 胶片影调 6 种：CC冷白、NC负片、清新、暖调、电影、复古
- 胶片影调浓度：30%/50%/70%/100% 四挡
- 美肤与胶片影调互斥，不能同时开
- D-Log 2 适合后期调色，直出党不用
- 胶片影调仅支持普通视频和慢动作模式
