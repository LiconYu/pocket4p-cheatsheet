① 快门 / ISO / 曝光补偿（曝光三要素）

拍摄界面 底部上滑 → 点右上角 PRO 开启高级模式 → 曝光选 M（手动） → 即可看到 快门 / ISO / EV 三个滑块

② 白平衡（让天空蓝、日落暖）

拍摄界面 左滑 → 找到 白平衡 → 选 手动 调节色温值（K值越小越冷/蓝，越大越暖/黄）

③ 色彩 / 机内影调 / 饱和度 / 锐度（直出关键）

拍摄界面 左滑 → 色彩 选 普通色彩 10bit → 开启 胶片影调 选 NC/CC/NV，浓度 70% → 图像调节：饱和度 +1、锐度 -1

④ 分辨率 / 帧率

拍摄界面 底部上滑 → 顶部 拍摄规格 → 选 4K 30fps 或 4K 60fps

⑤ 云台模式（街景/走路跟拍）

拍摄界面点 云台模式图标（左下角）或按 自定义按键 → 选 FPV（跟拍有代入感）/ 跟随 / 锁定
⚡ 自定义预设方案 C1/C2 · 一键切换场景

Pocket 4P 支持 自定义模式，可以把当前拍摄参数保存为 C1、C2 两套方案，之后一键调用，不用每次重新调。非常适合旅游时快速切换不同场景！

1
调出手动模式
底部上滑 → PRO → 曝光选 M，按上表调好该场景所有参数
2
保存为自定义
在参数界面找到 自定义模式（C1/C2），选择保存当前参数到 C1 或 C2
3
设置快捷切换
长按 自定义按键 → 功能设为 切换 C1/C2 或 C1 快速拍录
4
拍摄时一键切换
按一下自定义按键，即可在 C1 / C2 / 默认之间快速切换

🎯 推荐预设分配方案

预设位 推荐场景 核心参数 适用时机
C1 白天通用（山/水/街/蓝天） 广角、ISO100、1/60、ND16、WB锁定5200K、EV-0.7、纹理-1锐度-1 白天户外，光线充足
C2 日落/暖色场景 广角/中焦、ISO100-400、1/60、ND4、WB锁定5200K、EV-0.5、锁定曝光AE-L 傍晚日落前30-40分钟
默认(Auto) 夜景/室内 广角、不装ND、ISO100-1600、WB锁定4800K、EV-1.0、低光模式 晚上或光线暗时
💡 小白提示：
• 只有 2 个自定义位（C1/C2），建议把最常用的「白天通用」和「日落」存进去
• 夜景参数变化大，不建议存预设，现场用 Auto + 夜景模式更省心
• 切换预设后，记得检查 ND 滤镜是否装上了！预设只管参数，不会自动提醒你换滤镜
📌 ND 滤镜速记：轻度白天 ND8/16 · 强光白天 ND32/64 · 长曝光 ND1000 · 夜景不装
⚠️ 关键提醒：装ND后用手动曝光；白平衡锁定手动K值；夜景-1.0EV压噪点；美肤与胶片影调互斥
直出优化：普通色彩10bit + 胶片影调NC/CC浓度70% + 纹理-1 + 锐度-1 + 降噪0
